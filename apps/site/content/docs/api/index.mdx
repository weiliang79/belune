Every endpoint a personal access token can call, grouped by resource in the sidebar. Use this to look up one specific route by name or path.

If you are starting out — authenticating, choosing a scope, or finding out what a token can never do — read **[Getting Started](/docs/api/getting-started)** first. It also explains how this reference is produced, what it deliberately leaves out, and where to get the raw [OpenAPI spec](/openapi.json).

## Regenerating

```bash
task generate:api-docs
```

Runs against a disposable database — nothing it does touches a real install. Commit the result: Cloudflare Pages builds this site from `main` with no Go toolchain and no running API, so the output has to already be there.
